# Inquiries

This context defines a visitor's request for tailored help and how that intent differs from a resource request or scheduled meeting.

## Language

**Consultation inquiry**:
A request to discuss tailored help with Found42. It does not establish a scheduled meeting.
_Avoid_: Confirmed booking, instant scheduling

**Service interest**:
The category of help a visitor selects when making an inquiry. An interest label on a form is distinct from a published service name.

**C-Level AI Discovery Session**:
The one-to-one conversation promoted as using workshop experience and an AI Readiness Scorecard baseline to identify relevant opportunities and next steps.
_Avoid_: Confirmed booking when only a consultation inquiry has been made

**News and updates preference**:
A visitor's expressed choice about receiving Found42 news, distinct from the help or resource they request.

**Communications consent**:
The permission requested for further Found42 communications, distinct from the permission requested to store and process information for a request.

**Processing consent**:
The permission requested to store and process a visitor's personal information to provide requested content or services.
