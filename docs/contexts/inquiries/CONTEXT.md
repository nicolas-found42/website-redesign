# Inquiries

This context defines a visitor's request for tailored help and how that intent differs from a resource request or scheduled meeting.

## Language

**Consultation inquiry**:
A request to discuss tailored help with Found42. It does not establish a scheduled meeting.
_Avoid_: Confirmed booking, instant scheduling

**Service interest**:
The category of help a visitor selects when making an inquiry. An interest label on a form is distinct from a published service name.

**Resource request**:
A submission seeking access to a free resource. It does not by itself establish a request for consultation.
