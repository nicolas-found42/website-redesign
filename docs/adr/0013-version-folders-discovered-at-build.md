# Versions are folders, discovered at build

The repository holds many full iterations of the website. Each lives in its own
folder, `versions/<slug>/`, and the folders themselves are the only registry.

## Decision

- A version owns everything unique to it: markup, source, styles, assets,
  `version.json` (status, title, summary, author, created date), an optional
  `prerender.mjs`, and its own tests. Deleting the folder removes the version
  and every trace of it from the site.
- `scripts/build-site.mjs` discovers the folders, builds each to
  `dist/<slug>/` with its base path, generates a preview, and renders the hub
  index. No central list, route table, redirect file or Worker allowlist names
  a version.
- Shared code (`shared/`) never imports from a version, and a version never
  imports from another version. A test enforces both.
- `current` is the baseline: today's site, a folder like any other. Names for
  other versions are generated by `npm run version:new` and are never reused.
  Status changes by editing `version.json` in a pull request.
- Everything facts-shaped that versions share is in `shared/content`; the
  review tool is in `shared/review`.

## Consequences

- Adding a version is one folder; removing one is deleting it. CI cost is
  bounded because the per-version contract runs only for changed versions
  (all of them when shared code, the hub or tooling changes).
- The build injects a neutral hub strip (way back to the hub, version name and
  status) into every built page, so versions need no code for it and cannot
  omit it. Previews are captured without it.
- Old root-level paths no longer exist; `/website-redesign/` is the hub.
  Backwards-compatible redirects were explicitly declined.
- Feedback issues survive deletion of their version on GitHub; that history is
  the one thing the folder rule cannot remove.
- `current`'s own tests still live in the repository `tests/` directory, since
  they also protect the shared review tool and the Worker; a version's own tests
  belong in its folder.
- The design documents and ADRs 0001–0012 describe `current`. Other versions
  may depart from them.
