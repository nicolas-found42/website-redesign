# Resource content sources

The September 29 browser audit found unavailable starter files, a missing
five-day lesson sequence and essay cards with no reading destination. The user
requested existing material from Google Drive. These sources replace the newly
authored drafts, which are excluded from the pull request.

## Claude skill packages

The four archives in `public/resources/skills/` are byte-for-byte copies from
[Skills Files for Claude](https://drive.google.com/drive/folders/19vG_LgbVlB-If9G1YKh46u5961ORGvDz):

- `exec-comms-reviewer.skill`: executive communication review.
- `strategy-teardown.skill`: partner, ecosystem and channel strategy review.
- `strategic-advisor.skill`: advisor instructions, scenario prompts and a blank
  personal context template. No populated personal context is included.
- `context-audit.skill`: assumption audit and calibration interview.

The site delivers these files directly, without requiring Drive access. Package
instructions are preserved. Short catalog descriptions describe their intended
use; they make no claim of evaluated business results.

## Strategic Advisor

The original package and
[C-Level AI Claude Skills](https://docs.google.com/document/d/11y384HyRb6qwAlQkznxMNTkz9EkNl_v_JCPeGriBP_8/edit)
provide the context-template setup instructions. The existing
[published lesson](https://maven.com/p/fc1def/build-a-strategic-advisor-in-claude)
remains the learning destination. Drive searches found course strategy documents,
but no five-day lesson sequence. The resource therefore does not advertise five
lessons or course enrollment.

## Essay excerpts

The Blog page presents selected practical method sections from these existing
drafts, with shortened titles and editorial descriptions:

- [Reduce Shadow AI Risk](https://docs.google.com/document/d/1J-Oijd1VRzll6DPlqyM1WVzVNFpQG-LrH8iim5v-jC8/edit):
  routing, task/data mapping and a recurring review.
- [Preventing the Moral Crumple Zone](https://docs.google.com/document/d/1fy5kD7q76UVtLi3G4LjxKdDCsfJKq-28tRQA7RMl6ak/edit):
  verifiability, execution boundaries, monitoring and an agent audit.
- [The Partner Architecture Blueprint](https://docs.google.com/document/d/1LpYnnI1ujJMBreBFyvgxYC5WWKMY_yI7kr6mo6Du09c/edit):
  connected work, permissions, approval and capability intake.

Unverified statistics, legal conclusions and composite or unsubstantiated case
studies are omitted. The page identifies the material as draft excerpts awaiting
editorial review, without inventing author, date or reading time. The original
three placeholder titles are replaced rather than attributed to these sources.
Source documents remain in Drive with their existing permissions.
